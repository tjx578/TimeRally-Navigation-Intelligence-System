# Quality Gates

Quality gate adalah syarat rute bisa dipakai untuk lomba.

## Critical Gates

1. No placeholder coordinate.
2. No unresolved start/finish.
3. No broken sub-trayek chain.
4. Distance deviation within configured tolerance.
5. Time deviation within configured tolerance.
6. All inferred critical waypoints reviewed.
7. Offline package generated and opened successfully.

## Warning Gates

1. Provider disagreement above threshold.
2. Low source quality.
3. Route realism suspicious.
4. Coordinate stale.
5. OCR confidence low.
