# Tracking Gateway

Gateway untuk integrasi Traccar atau GPS tracker lain.

## Fungsi

- live vehicle position,
- geofence checkpoint,
- route deviation alert,
- replay GPS trace,
- compare planned vs actual,
- marshal dashboard.

## Data Contract

```yaml
gps_sample:
  vehicle_id: "car_01"
  timestamp: "2026-05-07T08:00:00+08:00"
  lat: -8.650000
  lng: 115.216667
  speed_kmh: 32.4
  heading_deg: 120
```
