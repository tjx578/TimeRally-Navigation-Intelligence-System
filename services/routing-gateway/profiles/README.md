Profiles mengatur cara routing engine memilih jalan.

## Profiles

```text
rally_car.json
```

## Rally Car Profile

Default untuk lomba:
- driving mode,
- no route reorder,
- avoid illegal turns,
- prefer road realism over shortest path,
- allow small local road only if soal implies it.
