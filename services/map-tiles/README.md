# Map Tiles Service

Map tiles service menyediakan basemap untuk MapLibre/Leaflet.

## Supported Formats

- MBTiles,
- PMTiles,
- vector tiles,
- raster tiles.

## Sources

Offline map harus berasal dari OSM atau sumber yang boleh dipaketkan. Google tiles tidak boleh dicache untuk offline navigation.

## Output

```text
style.json
tiles.pmtiles
region.mbtiles
attribution.json
```
