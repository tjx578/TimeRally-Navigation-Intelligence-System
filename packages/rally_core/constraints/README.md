# Constraints

Constraint engine memastikan rute tidak hanya logis, tetapi sesuai soal.

## Checks

- total distance binding,
- total time binding,
- sub-trayek distance binding,
- sub-trayek time binding,
- waypoint chaining,
- coordinate precision,
- route realism,
- speed realism.

## Status

```text
compliant
warning
violation
disqualified
```
