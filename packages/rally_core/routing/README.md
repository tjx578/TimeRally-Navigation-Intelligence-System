# Rally Routing Domain

Modul ini menyimpan model domain routing, bukan implementasi provider.

Models:
- RouteRequest,
- RouteSegment,
- ProviderResult,
- ProviderComparison,
- RouteValidationContext,
- RoadbookLeg.

Rule:
- Domain model harus bisa menerima hasil dari Valhalla, OSRM, GraphHopper, dan Google dalam format yang sama.
