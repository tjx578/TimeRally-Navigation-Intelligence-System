# Parser

Tugas parser:

- normalisasi teks,
- deteksi sub-trayek,
- deteksi total jarak dan total waktu,
- deteksi mode kecepatan,
- parse waypoint,
- parse action-landmark relation,
- parse KMPAL pattern,
- output structured rally event.

Parser tidak melakukan routing. Parser hanya mengubah soal menjadi struktur.
