# PWA Offline Mode

Field mobile should start as a PWA before native mobile.

## Why PWA First

- Faster to build.
- Can reuse web UI components.
- Works on tablets and laptops.
- Can cache roadbook and offline package.

## Offline Capabilities

- Load route package.
- Show roadbook.
- Show current GPS position.
- Show next turn.
- Record GPS trace.
- Warn if off corridor.

## Safety Rule

During race, offline app must not silently replace the official route. It may suggest a correction, but the locked rally route remains visible.
