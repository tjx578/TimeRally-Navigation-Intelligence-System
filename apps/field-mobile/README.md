# Field Mobile

Mobile shell untuk navigator/co-driver.

## Mode

- Offline package mode.
- Live tracking mode.
- Roadbook only mode.

## Data Yang Dibawa Ke Lapangan

```text
event.yaml
route.geojson
route.gpx
route.kml
offline-map.pmtiles
roadbook.json
validation-report.json
```

## Prinsip

Saat lomba, mobile app tidak boleh mengubah rute diam-diam. Re-route hanya boleh terjadi sebagai advisory dan harus tetap menjaga urutan soal.
