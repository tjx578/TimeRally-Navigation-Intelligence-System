# Rally Map Feature

Layer yang wajib:

- basemap offline/online,
- route polyline per sub-trayek,
- waypoint marker,
- inferred waypoint marker,
- warning marker,
- route corridor,
- GPS trace overlay,
- checkpoint/geofence.

Interaction:
- click waypoint -> detail source/confidence,
- drag candidate -> recompute leg,
- compare provider -> show distance/time deltas.
