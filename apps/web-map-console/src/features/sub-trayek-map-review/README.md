# Sub-Trayek Map Review

Fitur ini membuat tiap sub-trayek menjadi unit kerja navigator.

## Cara Kerja

- Sub A-G tampil sebagai tab ringkas.
- Klik tab A menampilkan route sub A di peta.
- Klik tab B menampilkan route sub B, dan seterusnya.
- Tombol `Finish Sub Ini` memasukkan sub aktif ke roadbook.
- Setelah satu sub selesai, sistem memajukan fokus ke sub berikutnya.

## Mode Lomba

Saat driver menjalankan sub A, navigator bisa mulai review sub B. Setelah sub A selesai, roadbook sub A sudah tersedia, dan sub B sudah lebih siap. Tujuannya mempercepat kerja navigator tanpa kehilangan validasi total jarak/waktu.
