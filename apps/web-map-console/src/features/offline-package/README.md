# Offline Package Feature

Builds the package used in the field.

Package contents:

```text
event.yaml
roadbook.json
route.geojson
route.gpx
route.kml
validation-report.json
candidate-review.json
offline-map.pmtiles
manifest.json
```

UI actions:
- build package,
- verify package,
- download/open package,
- sync package to mobile field app.
